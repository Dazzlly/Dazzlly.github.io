# Dazzlly

Portfólio de **Lucas Arruda Oliveira** (Dazzlly) — Mecânico Auto Elétrico de Scooters, Técnico em Informática, Criador de Conteúdo e estudante de Engenharia de Software.

## Páginas

- **Início** — Apresentação, destaques, números e depoimentos
- **Hobbies** — Interesses e hobbies pessoais
- **Carreira** — Timeline da trajetória profissional
- **Formação** — Escolaridade, cursos e certificados de conclusão
- **Eventos** — Eventos e certificados de participação
- **Projetos** — Projetos pessoais e profissionais
- **Social** — Redes sociais + player Twitch ao vivo / YouTube (toggle)
- **Contato** — Formulário de contato e canais diretos

## Stack

- **Jekyll** — Site estático
- **GitHub Pages** — Hospedagem (domínio: www.dazzlly.com)
- CSS e JS customizados — sem frameworks, leve e rápido

## Desenvolvimento local

```bash
docker compose -f docker-compose.base44.yml up -d
```
